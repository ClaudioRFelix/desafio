# App (desafio)

Ojbetivo: Aplicativo simples de cadastro de pessoa física e/ou jurídica

### Instruções App

## Backend

```bash
npm i
node registration.js
```

http://localhost:3000/

## Frontend

```bash
npm install
npm run dev
```

http://localhost:5173/

## Ambiente de desenvolvimento NodeJS no Windows

- VsCode última versão https://code.visualstudio.com/
- NodeJS última versão https://nodejs.org/en/
- Quasar Última versão https://quasar.dev/
  Instalação de forma global precisa ser administrador
- Postman última versão Free https://www.postman.com/
- 7-Zip https://www.7-zip.org/

- NPM última versão (instalado junto com o instalador do NodeJS);
- MySql 8.0 https://www.mysql.com/ (*)
- MySQLWorkbench (instalação junto com o instalador do MySql) (*)
- Framework Vue (instalação realizada pelo "cmd" do windows) https://quasar.dev/
  npm install -g @quasar/cli
- Download dos Programas fontes diretamente do github (vamos criar um acesso no github pela Unimed Rio) 
- Todos as dependências de pacotes de back-end e front-end são instaladas pelo pacote "NPM" nas pastas dos aplicativos;

(*) APENAS PARA TESTE NA SUA MAQUIANA PARTICULAR, NÃO USAREMOS NO PROJETO UNIMED RIO GESTOR
